# Inbox

Buffer tạm để capture nhanh — ý tưởng, việc cần làm, thứ chưa rõ thuộc dự án/Knowledge/Learning nào. **Không phải kho lưu trữ.**

- Chưa rõ thuộc đâu → ghi thẳng vào đây, không cần nghĩ cấu trúc.
- Review định kỳ hàng tuần, promote sang nơi phù hợp hoặc xóa nếu hết giá trị — xem [[80_System/WORKFLOW#2. Inbox Aging]].
- Đây là **ngoại lệ duy nhất** được xóa thẳng thay vì archive.
